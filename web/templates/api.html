CalDAV Geräte-Setup

Der Client soll ZentCal über die Serveradresse erkennen. Eine lange Kalender-URL ist nicht nötig.

Passwort: App-Passwort aus deinen Kontoeinstellungen.
Serveradresse{{index .Data "DAVHost"}}Port{{index .Data "DAVPort"}}SSL{{if index .Data "DAVSSL"}}Ja{{else}}Nein{{end}}Serverpfad/Benutzername{{.User.Email}}

Bei macOS/iPhone reicht normalerweise die Serveradresse; falls ein Serverpfad verlangt wird, / verwenden. ZentCal wird anschließend automatisch über CalDAV Discovery gefunden.
